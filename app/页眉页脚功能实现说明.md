# 页眉页脚功能实现 - 修复说明

## 问题描述

阅读器中的页眉页脚功能存在问题：
1. UI上有开关和字体大小调节控件
2. 有变量定义（showHeaderFooter、headerFooterFontSize）
3. **但没有实际实现**：reader.html中没有绘制代码
4. **没有保存/加载**：设置不会被持久化
5. **没有调用接口**：UI操作不会触发WebView更新

**现象**：
- 用户打开/关闭页眉页脚开关，没有任何变化
- 调整字体大小，没有任何变化
- 关闭应用后重新打开，设置丢失

#### 2. reader.html - 修改分页计算

#### 3. reader.html - 添加页眉页脚绘制

**位置**：drawPage() 函数

```javascript
function drawPage(pageIndex) {
    ctx.clearRect(0, 0, window.innerWidth, window.innerHeight);
    ctx.fillStyle = bgColor;
    ctx.fillRect(0, 0, window.innerWidth, window.innerHeight);

    if (pageIndex < 0 || pageIndex >= pages.length) return;

    var lines = pages[pageIndex];
    var y = padding;
    var maxY = window.innerHeight - bottomPadding;
    
    // ✅ 绘制页眉（如果启用）
    if (showHeaderFooter && chapterTitle) {
        ctx.font = headerFooterFontSize + 'px sans-serif';
        ctx.fillStyle = textColor;
        ctx.textAlign = 'center';
        ctx.fillText(chapterTitle, window.innerWidth / 2, padding + headerFooterFontSize);
        ctx.textAlign = 'left'; // 重置对齐方式
        y = padding + headerFooterFontSize + 10; // 页眉后留10px间距
    }
    
    // ... 绘制正文内容 ...
    
    // ✅ 绘制页脚（如果启用）
    if (showHeaderFooter && pages.length > 0) {
        var footerText = (pageIndex + 1) + '/' + pages.length;
        ctx.font = headerFooterFontSize + 'px sans-serif';
        ctx.fillStyle = textColor;
        ctx.textAlign = 'center';
        ctx.fillText(footerText, window.innerWidth / 2, window.innerHeight - 15);
        ctx.textAlign = 'left'; // 重置对齐方式
    }
}
```

**说明**：
- **页眉**：显示章节标题，居中对齐，位于顶部
- **页脚**：显示页码（当前页/总页数），居中对齐，位于底部
- **条件判断**：只在showHeaderFooter为true时绘制

```java
private void saveReadingPreferences() {
    SharedPreferences sp = getSharedPreferences("read_settings", MODE_PRIVATE);
    sp.edit()
            .putFloat("font_size", currentFontSize)
            .putBoolean("night_mode", isNightMode)
            .putInt("brightness", currentBrightness)
            .putBoolean("follow_system_brightness", followSystemBrightness)
            .putInt("bg_color", currentBgColor)
            // ✅ 保存页眉页脚设置
            .putBoolean("show_header_footer", showHeaderFooter)
            .putFloat("header_footer_font_size", headerFooterFontSize)
            .apply();
    uploadProgressToServer();
}
```

## 功能特性

### 1. 页眉显示

**内容**：当前章节标题
**位置**：顶部居中
**样式**：
- 字体大小：可调节（10-30px，默认18px）
- 颜色：跟随正文颜色（日间/夜间模式自动切换）
- 对齐：居中

**示例**：
```
┌─────────────────────────┐
│      第5章(上)          │  ← 页眉
│                         │
│   正文内容开始...       │
│   ...                   │
```

### 2. 页脚显示

**内容**：当前页/总页数
**位置**：底部居中
**样式**：
- 字体大小：与页眉相同
- 颜色：跟随正文颜色
- 对齐：居中

**示例**：
```
│   ...正文内容结束       │
│                         │
│        3/10             │  ← 页脚
└─────────────────────────┘
```

### 3. 智能布局

**页眉占用空间**：
- 分页计算时自动减去页眉高度
- 避免正文与页眉重叠
- 页眉后留10px间距

**计算公式**：
```javascript
if (showHeaderFooter && title) {
    maxHeight -= (headerFooterFontSize + 10);
}
```

### 4. 设置持久化

**保存内容**：
- `show_header_footer`: boolean（是否显示）
- `header_footer_font_size`: float（字体大小）

**存储位置**：SharedPreferences ("read_settings")

**默认值**：
- 显示：true
- 字体大小：18px

## 技术细节

### Canvas文本绘制

```javascript
// 设置字体
ctx.font = headerFooterFontSize + 'px sans-serif';

// 设置颜色
ctx.fillStyle = textColor;

// 设置对齐方式
ctx.textAlign = 'center';

// 绘制文本
ctx.fillText(text, x, y);

// 重置对齐方式
ctx.textAlign = 'left';
```

### JavaScript与Java通信

**Java调用JS**：
```java
webView.evaluateJavascript("setShowHeaderFooter(true)", null);
webView.evaluateJavascript("setHeaderFooterFontSize(20)", null);
```

**注意**：
- evaluateJavascript是异步的
- 不需要返回值时使用null回调
- 参数需要正确转义

### 布局计算

**可用高度计算**：
```
总高度: window.innerHeight
顶部边距: padding (16px)
底部边距: bottomPadding (40px)
页眉高度: headerFooterFontSize + 10px (如果显示)

可用高度 = 总高度 - 顶部边距 - 底部边距 - 页眉高度
```

**页眉位置**：
```
y = padding + headerFooterFontSize
```

**页脚位置**：
```
y = window.innerHeight - 15
```
