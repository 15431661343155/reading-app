# 页眉页脚样式优化与设置保存修复 - 完成说明

## 需求描述

1. **页眉与页脚字体改为浅灰色**
2. **页眉与页脚初始字号调小到12**
3. **页眉与页脚字号调节范围改到8-24**
4. **修复设置保存问题**（每次退出阅读器重新进入页眉页脚会还原为默认）

## 问题分析

### 原始状态

**字体颜色**：
- ❌ 使用 `textColor`（正文颜色，深色）
- 应该使用浅灰色以区分正文

**初始字号**：
- ❌ 默认为 18px
- 应该调整为 12px 更小巧

**字号范围**：
- ❌ 调节范围为 10-30
- 应该调整为 8-24 更合理

**设置保存问题**：
- ✅ 有保存逻辑：`saveReadingPreferences()` 中保存了 `show_header_footer` 和 `header_footer_font_size`
- ✅ 有加载逻辑：`loadReadingPreferencesNoApply()` 中加载了这两个变量
- ❌ **但没有应用逻辑**：加载后没有调用 JavaScript 接口将设置应用到 WebView
- **结果**：虽然变量加载正确，但 WebView 中的显示仍然是默认值

### 3. ReadActivity.java - 修复设置保存问题

#### 3.1 问题分析

**原始流程**：
```
启动阅读器
  ↓
loadReadingPreferencesNoApply()  ← 加载设置到变量
  ↓
loadChaptersFromServer()
  ↓
loadChapterContent(0)
  ↓
renderChapterContent()  ← 渲染章节
  ↓
webView.evaluateJavascript("loadContent(...)")  ← 调用JS加载内容
  ↓
❌ 没有应用页眉页脚设置！
```

**问题**：虽然 `loadReadingPreferencesNoApply()` 加载了设置到 Java 变量，但没有将这些设置传递给 WebView。

#### 3.2 解决方案

**添加 applyHeaderFooterSettings() 方法**（第580-588行）：

```java
/**
 * ✅ 应用页眉页脚设置到 WebView
 */
private void applyHeaderFooterSettings() {
    if (isWebViewReady) {
        webView.evaluateJavascript("setShowHeaderFooter(" + showHeaderFooter + ")", null);
        webView.evaluateJavascript("setHeaderFooterFontSize(" + (int)headerFooterFontSize + ")", null);
    }
}
```

**在 renderChapterContent() 中调用**（第576-578行）：

```java
private void renderChapterContent(int chapterIndex, String title, String content) {
    // ... 原有代码 ...
    
    webView.evaluateJavascript(js, null);
    currentChapterIndex = chapterIndex;
    updateChapterButtons();
    
    // ✅ 应用页眉页脚设置到 WebView
    applyHeaderFooterSettings();
}
```

## 技术细节

### 1. 颜色选择

**浅灰色 #999999**：
- RGB: (153, 153, 153)
- 亮度适中，既不会太淡看不清，也不会太深抢正文风头
- 在浅色背景和深色背景下都有良好的对比度

**备选颜色**：
- `#AAAAAA`：更浅一些
- `#888888`：更深一些
- `#CCCCCC`：最浅

### 2. 字号选择

**初始12px的理由**：
- 足够小，不占用太多空间
- 足够大，保证可读性
- 适合显示章节标题和页码

**范围8-24的理由**：
- 最小8px：极限情况，适合小屏幕或需要最大化阅读空间
- 最大24px：适合视力不佳的用户
- 跨度16px，提供足够的调节空间

### 3. 设置保存机制

**SharedPreferences存储**：
```java
// 保存
sp.edit()
    .putBoolean("show_header_footer", showHeaderFooter)
    .putFloat("header_footer_font_size", headerFooterFontSize)
    .apply();

// 加载
showHeaderFooter = sp.getBoolean("show_header_footer", true);
headerFooterFontSize = sp.getFloat("header_footer_font_size", 12f);
```

**JavaScript接口同步**：
```java
// 应用设置
webView.evaluateJavascript("setShowHeaderFooter(" + showHeaderFooter + ")", null);
webView.evaluateJavascript("setHeaderFooterFontSize(" + (int)headerFooterFontSize + ")", null);
```

## 注意事项

1. **颜色适配**：如果未来支持自定义主题，需要考虑页眉页脚颜色的适配
2. **字号限制**：当前限制8-24，如果需要更大范围可以调整
3. **性能考虑**：每次渲染章节都调用两次evaluateJavascript，性能影响可忽略
4. **兼容性**：确保旧版本的SharedPreferences数据能正确迁移
