# 主题系统快速测试指南

## 🧪 测试步骤

### 1. 编译项目
```bash
# 在Android Studio中
Build → Rebuild Project

# 或使用命令行
./gradlew clean build
```

### 2. 运行应用
- 启动应用
- 确保没有编译错误

### 3. 测试主题切换

#### 步骤A：进入主题设置
1. 打开应用
2. 点击底部导航栏的"我的"
3. 找到并点击"主题设置"按钮

#### 步骤B：切换主题
1. 你会看到四个主题卡片：
   - 🌊 清新海洋（默认）
   - 💜 优雅紫罗兰
   - 🌲 自然森林
   - 🌅 暖阳橙光

2. 点击任意一个主题卡片
3. **观察效果**：
   - ✅ 主题立即切换（无需重启）
   - ✅ 选中的主题显示对勾标记
   - ✅ 选中的主题边框高亮
   - ✅ 出现Toast提示"已切换到XXX主题"

4. 再次点击其他主题，重复测试

#### 步骤C：验证持久化
1. 切换到一个主题（如"优雅紫罗兰"）
2. 完全关闭应用（从最近任务中移除）
3. 重新打开应用
4. 进入主题设置
5. **验证**：应该仍然显示"优雅紫罗兰"为选中状态

### 4. 测试不同页面

#### 测试主页
1. 切换主题后
2. 返回主页（书城/书架/我的）
3. **验证**：所有页面都应用了新主题颜色

#### 测试阅读页面
1. 打开一本书
2. 进入阅读页面
3. **验证**：
   - 顶部导航栏使用新主题颜色
   - 底部导航栏使用新主题颜色
   - 文字颜色正确

### 5. 边界情况测试

#### 测试1：重复选择同一主题
1. 当前主题是"清新海洋"
2. 再次点击"清新海洋"
3. **预期**：Toast提示"当前已是该主题"

#### 测试2：快速切换
1. 快速连续点击不同主题
2. **预期**：每次都能正常切换，无崩溃

#### 测试3：旋转屏幕
1. 切换主题
2. 旋转屏幕
3. **预期**：主题保持不变

- [ ] 能够进入主题设置页面

- [ ] 点击主题后立即生效（无需重启）

## 🐛 常见问题排查

### 问题1：点击主题后没有反应
**可能原因**：ThemeManager未正确初始化  
**解决**：检查BaseActivity是否正确调用ThemeManager

### 问题2：主题切换后部分页面颜色不对
**可能原因**：布局文件使用了硬编码颜色  
**解决**：将硬编码颜色改为主题属性，如 `?attr/navBg`

### 问题3：重启后主题恢复默认
**可能原因**：SharedPreferences未正确保存  
**解决**：检查ThemeManager中的save逻辑

### 问题4：编译错误
**可能原因**：缺少依赖或资源文件  
**解决**：
1. 清理项目：Build → Clean Project
2. 重新构建：Build → Rebuild Project
3. 检查gradle依赖是否包含Material Components

- 应在100ms以内

- 应短暂升高后迅速恢复
