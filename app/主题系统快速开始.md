# 主题系统快速开始指南

## 🚀 5分钟快速集成主题系统

### 步骤1：更新 BaseActivity

在你的 `BaseActivity.java` 中添加主题应用逻辑：

```java
public class BaseActivity extends AppCompatActivity {
    
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        // ✅ 关键：在super.onCreate之前应用主题
        applyTheme();
        super.onCreate(savedInstanceState);
    }
    
    /**
     * 应用用户选择的主题
     */
    private void applyTheme() {
        SharedPreferences prefs = getSharedPreferences("app_settings", MODE_PRIVATE);
        String theme = prefs.getString("theme", "ocean");
        
        switch (theme) {
            case "ocean":
                setTheme(R.style.Theme_MyApp_Ocean);
                break;
            case "violet":
                setTheme(R.style.Theme_MyApp_Violet);
                break;
            case "forest":
                setTheme(R.style.Theme_MyApp_Forest);
                break;
            case "sunset":
                setTheme(R.style.Theme_MyApp_Sunset);
                break;
            default:
                setTheme(R.style.Theme_MyApp_Ocean);
                break;
        }
    }
}
```

### 步骤2：实现 ThemeSettingActivity

将 `ThemeSettingActivity示例代码.java` 中的代码复制到你的项目中：

1. 打开 `ThemeSettingActivity示例代码.java`
2. 复制所有代码
3. 粘贴到你的 `com.example.myapplication.activity.ThemeSettingActivity` 类中
4. 确保导入语句正确

### 步骤3：在 AndroidManifest.xml 中注册

```xml
<activity 
    android:name=".activity.ThemeSettingActivity"
    android:label="主题设置"
    android:theme="@style/Theme.MyApp.Ocean" />
```

### 步骤4：添加主题切换入口

在你的"我的"页面或设置页面添加主题切换按钮：

```xml
<!-- 在 fragment_mine.xml 或设置页面 -->
<LinearLayout
    android:id="@+id/layout_theme_setting"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:padding="16dp"
    android:background="?attr/cardBackgroundColor"
    android:clickable="true"
    android:focusable="true">

    <ImageView
        android:layout_width="24dp"
        android:layout_height="24dp"
        android:src="@drawable/ic_theme_settings" />

    <TextView
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="主题设置"
        android:textSize="16sp"
        android:textColor="?attr/textPrimaryColor"
        android:layout_marginStart="16dp" />
</LinearLayout>
```

在对应的Fragment或Activity中添加点击事件：

```java
findViewById(R.id.layout_theme_setting).setOnClickListener(v -> {
    Intent intent = new Intent(getActivity(), ThemeSettingActivity.class);
    startActivity(intent);
});
```

### 步骤5：测试主题切换

1. 运行应用
2. 进入"我的"页面
3. 点击"主题设置"
4. 选择你喜欢的主题
5. 应用会自动重启并应用新主题

## ✨ 完成！

现在你的应用已经支持四个精美主题了！

## 📝 注意事项

1. **所有Activity必须继承BaseActivity**
   - 这样才能自动应用主题
   - 如果有Activity不能继承BaseActivity，需要手动调用applyTheme()

2. **主题切换会重启应用**
   - 这是Android主题系统的限制
   - 用户体验仍然流畅（有淡入淡出动画）

3. **首次安装默认使用海洋主题**
   - 用户可以通过设置随时切换

4. **主题偏好会被保存**
   - 下次启动应用时自动应用上次选择的主题

## 🔧 故障排除

### 问题1：主题没有生效
**解决**：检查是否在 `setContentView()` 之前调用了 `setTheme()`

### 问题2：编译错误
**解决**：确保已添加 Material Components 依赖
```gradle
implementation 'com.google.android.material:material:1.9.0'
```

### 问题3：颜色不对
**解决**：清理并重新构建项目
```
Build → Clean Project
Build → Rebuild Project
```

### 问题4：布局没有使用主题颜色
**解决**：检查布局文件是否使用了主题属性
- ❌ `android:background="#FFFFFF"`
- ✅ `android:background="?attr/navBg"`
