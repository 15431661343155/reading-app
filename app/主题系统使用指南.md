# 主题系统使用指南

## 📚 概述

本应用现已支持四个精美的可切换主题，每个主题都有独特的配色方案和视觉风格。

## 🎨 四个主题介绍

### 1. 清新海洋 (Ocean) - 默认主题
- **主色调**：天蓝色 (#2196F3)
- **特点**：清爽舒适，如海风般宜人
- **适用场景**：日常阅读，长时间使用不疲劳

### 2. 优雅紫罗兰 (Violet)
- **主色调**：紫色 (#9C27B0)
- **特点**：高贵典雅，彰显品味
- **适用场景**：夜间阅读，营造浪漫氛围

### 3. 自然森林 (Forest)
- **主色调**：绿色 (#4CAF50)
- **特点**：生机勃勃，亲近自然
- **适用场景**：户外阅读，护眼舒适

### 4. 暖阳橙光 (Sunset)
- **主色调**：橙色 (#FF9800)
- **特点**：温暖温馨，如夕阳般柔和
- **适用场景**：黄昏阅读，温暖心情

## 🔧 如何在代码中切换主题

### 方法1：在Activity启动前设置主题

```java
// 在 setContentView() 之前调用
@Override
protected void onCreate(Bundle savedInstanceState) {
    // 从SharedPreferences读取用户选择的主题
    SharedPreferences prefs = getSharedPreferences("app_settings", MODE_PRIVATE);
    String theme = prefs.getString("theme", "ocean");
    
    // 应用主题
    switch (theme) {
        case "ocean":
            setTheme(R.style.Theme_MyApp_Ocean);
            break;
        case "violet":
            setTheme(R.style.Theme_MyApp_Violet);
            break;
        case "forest":
            setTheme(R.style.Theme_MyApp_Forest);
            break;
        case "sunset":
            setTheme(R.style.Theme_MyApp_Sunset);
            break;
        default:
            setTheme(R.style.Theme_MyApp_Ocean);
            break;
    }
    
    super.onCreate(savedInstanceState);
    setContentView(R.layout.activity_main);
}
```

### 方法2：动态切换主题（需要重启Activity）

```java
private void applyTheme(String themeName) {
    SharedPreferences prefs = getSharedPreferences("app_settings", MODE_PRIVATE);
    prefs.edit().putString("theme", themeName).apply();
    
    // 重启当前Activity以应用新主题
    Intent intent = getIntent();
    finish();
    startActivity(intent);
    overridePendingTransition(android.R.anim.fade_in, android.R.anim.fade_out);
}
```

## 📝 主题选择器实现示例

在 `ThemeSettingActivity.java` 中：

```java
public class ThemeSettingActivity extends BaseActivity {
    
    private MaterialCardView cardOcean, cardViolet, cardForest, cardSunset;
    private ImageView ivOceanCheck, ivVioletCheck, ivForestCheck, ivSunsetCheck;
    private String currentTheme;
    
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        // 必须在super.onCreate之前设置主题
        applyCurrentTheme();
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_theme_setting);
        
        initViews();
        loadCurrentTheme();
        setupClickListeners();
    }
    
    private void applyCurrentTheme() {
        SharedPreferences prefs = getSharedPreferences("app_settings", MODE_PRIVATE);
        currentTheme = prefs.getString("theme", "ocean");
        
        switch (currentTheme) {
            case "ocean":
                setTheme(R.style.Theme_MyApp_Ocean);
                break;
            case "violet":
                setTheme(R.style.Theme_MyApp_Violet);
                break;
            case "forest":
                setTheme(R.style.Theme_MyApp_Forest);
                break;
            case "sunset":
                setTheme(R.style.Theme_MyApp_Sunset);
                break;
        }
    }
    
    private void initViews() {
        cardOcean = findViewById(R.id.card_ocean);
        cardViolet = findViewById(R.id.card_violet);
        cardForest = findViewById(R.id.card_forest);
        cardSunset = findViewById(R.id.card_sunset);
        
        ivOceanCheck = findViewById(R.id.iv_ocean_check);
        ivVioletCheck = findViewById(R.id.iv_violet_check);
        ivForestCheck = findViewById(R.id.iv_forest_check);
        ivSunsetCheck = findViewById(R.id.iv_sunset_check);
    }
    
    private void loadCurrentTheme() {
        // 隐藏所有选中标记
        ivOceanCheck.setVisibility(View.GONE);
        ivVioletCheck.setVisibility(View.GONE);
        ivForestCheck.setVisibility(View.GONE);
        ivSunsetCheck.setVisibility(View.GONE);
        
        // 重置所有卡片边框
        resetCardBorders();
        
        // 显示当前主题的选中标记和高亮边框
        switch (currentTheme) {
            case "ocean":
                ivOceanCheck.setVisibility(View.VISIBLE);
                highlightCard(cardOcean, R.color.ocean_primary);
                break;
            case "violet":
                ivVioletCheck.setVisibility(View.VISIBLE);
                highlightCard(cardViolet, R.color.violet_primary);
                break;
            case "forest":
                ivForestCheck.setVisibility(View.VISIBLE);
                highlightCard(cardForest, R.color.forest_primary);
                break;
            case "sunset":
                ivSunsetCheck.setVisibility(View.VISIBLE);
                highlightCard(cardSunset, R.color.sunset_primary);
                break;
        }
    }
    
    private void setupClickListeners() {
        cardOcean.setOnClickListener(v -> selectTheme("ocean"));
        cardViolet.setOnClickListener(v -> selectTheme("violet"));
        cardForest.setOnClickListener(v -> selectTheme("forest"));
        cardSunset.setOnClickListener(v -> selectTheme("sunset"));
        
        findViewById(R.id.toolbar_back).setOnClickListener(v -> finish());
    }
    
    private void selectTheme(String theme) {
        if (theme.equals(currentTheme)) return;
        
        // 保存主题选择
        SharedPreferences prefs = getSharedPreferences("app_settings", MODE_PRIVATE);
        prefs.edit().putString("theme", theme).apply();
        
        Toast.makeText(this, "主题已切换，重启应用生效", Toast.LENGTH_SHORT).show();
        
        // 延迟重启以显示提示
        new Handler(Looper.getMainLooper()).postDelayed(() -> {
            restartApp();
        }, 1000);
    }
    
    private void restartApp() {
        Intent intent = new Intent(this, MainActivity.class);
        intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK | Intent.FLAG_ACTIVITY_CLEAR_TASK);
        startActivity(intent);
        finish();
    }
    
    private void resetCardBorders() {
        ((MaterialCardView)cardOcean).setStrokeColor(Color.parseColor("#E0E0E0"));
        ((MaterialCardView)cardViolet).setStrokeColor(Color.parseColor("#E0E0E0"));
        ((MaterialCardView)cardForest).setStrokeColor(Color.parseColor("#E0E0E0"));
        ((MaterialCardView)cardSunset).setStrokeColor(Color.parseColor("#E0E0E0"));
    }
    
    private void highlightCard(MaterialCardView card, int colorRes) {
        int color = ContextCompat.getColor(this, colorRes);
        card.setStrokeColor(color);
    }
}
```

## 🎯 在布局中使用主题属性

### 示例1：使用主题背景色

```xml
<LinearLayout
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:background="?attr/android:windowBackground">
```

### 示例2：使用主题文字颜色

```xml
<TextView
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:textColor="?attr/textPrimaryColor"
    android:text="主要文字"/>

<TextView
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:textColor="?attr/textSecondaryColor"
    android:text="次要文字"/>
```

### 示例3：使用主题卡片背景

```xml
<com.google.android.material.card.MaterialCardView
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    app:cardBackgroundColor="?attr/cardBackgroundColor">
```

### 示例4：使用主题导航栏颜色

```xml
<com.google.android.material.bottomnavigation.BottomNavigationView
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:background="?attr/navBg"
    app:itemIconTint="@color/nav_item_color"
    app:itemTextColor="@color/nav_item_text_color"/>
```

## 🌙 夜间模式支持

所有主题都继承了 `DayNight` 特性，自动支持系统的深色模式。如需自定义夜间颜色，可在 `res/values-night/colors.xml` 中覆盖相应颜色值。

## 💡 最佳实践

1. **在Application类中初始化主题**
   ```java
   public class MyApplication extends Application {
       @Override
       public void onCreate() {
           super.onCreate();
           // 确保主题在所有Activity之前加载
       }
   }
   ```

2. **统一的主题切换入口**
   - 建议在"我的"页面或设置页面提供主题切换入口
   - 切换后提示用户重启应用

3. **记住用户选择**
   - 使用SharedPreferences保存用户的主题偏好
   - 每次启动应用时自动应用上次选择的主题

4. **平滑过渡**
   - 切换主题时使用淡入淡出动画
   - 避免生硬的界面跳转

## 📱 兼容性说明

- 最低支持 Android 5.0 (API 21)
- 推荐使用 Material Components 库
- 所有主题都基于 Material Design 规范

## 🎨 自定义扩展

如需添加新主题，只需：
1. 在 `colors.xml` 中添加新颜色的定义
2. 在 `themes.xml` 中创建新的主题样式
3. 在主题选择器UI中添加新选项
4. 更新主题切换逻辑
