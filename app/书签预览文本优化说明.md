# 书签预览文本优化 - 显示当前页内容

## 问题描述

用户反馈：**"书签管理的预览文本应为加书签的页的内容"**

**现象**：
1. 用户在第5章的第3页添加书签
2. 书签预览显示的是**第5章开头的前100字** ❌
3. 但用户希望看到的是**第3页的内容** ✅

## 问题根源分析

### 原始代码问题

**文件**：[ReadActivity.java#L1177-1182](file:///d:/android/app/app/src/main/java/com/example/myapplication/activity/ReadActivity.java#L1177-L1182)（修复前）

```java

    if (fullContent != null && fullContent.length() > 0) {
        contentPreview = fullContent.length() > 100 ? fullContent.substring(0, 100) + "..." : fullContent;
    }
    ...

```

**问题分析**：
1. **获取的是整个章节的内容**：`chapterContents.get(currentChapterIndex)`
2. **截取前100字**：`substring(0, 100)`
3. **结果**：无论用户在哪个页面添加书签，预览都是章节开头的内容

**示例**：
```
假设第5章有10页，用户在第8页添加书签：

原始逻辑：
  → 获取第5章全部内容（10页）
  → 截取前100字（第1页的开头）
  → 预览显示："第一章的开头内容..." ❌
  
期望逻辑：
  → 获取第8页的内容
  → 截取前100字
  → 预览显示："第八章的内容..." ✅
```

### 技术难点

**分页是在 WebView 中完成的**：
- Java 层只有整个章节的原始文本
- 分页逻辑在 `reader.html` 的 JavaScript 中
- Java 层不知道每一页的具体内容

**解决方案**：
- 在 JavaScript 中添加函数获取当前页内容
- Java 层调用 JavaScript 函数获取内容

## 修复方案

### 核心原则：**从 WebView 获取当前页的内容作为预览**

### 修改点1：reader.html - 添加 getCurrentPageText 函数

**文件**：[reader.html#L267-284](file:///d:/android/app/app/src/main/assets/reader.html#L267-L284)

```javascript
// ✅ 新增：获取当前页的文本内容（用于书签预览）
function getCurrentPageText() {
    if (currentPage < 0 || currentPage >= pages.length) return "";
    
    var lines = pages[currentPage];
    if (!lines || lines.length === 0) return "";
    
    // 提取所有行的文本，用换行符连接
    var textLines = [];
    for (var i = 0; i < lines.length; i++) {
        if (lines[i].text && lines[i].text.trim() !== "") {
            textLines.push(lines[i].text);
        }
    }
    
    return textLines.join("\n");
}
```

**改进**：
1. **检查边界**：确保 currentPage 有效
2. **提取文本**：遍历当前页的所有行
3. **过滤空行**：只保留非空文本
4. **换行连接**：用 `\n` 连接各行，保持格式

### 修改点2：addLocalBookmark - 调用 JavaScript 获取内容

**文件**：[ReadActivity.java#L1175-1218](file:///d:/android/app/app/src/main/java/com/example/myapplication/activity/ReadActivity.java#L1175-L1218)

```java
private void addLocalBookmark() {
    String chapterTitle = chapterList.get(currentChapterIndex).getTitle();
    
    // ✅ 修正：从 WebView 获取当前页的内容作为预览
    final String[] contentPreview = {""};
    
    if (isWebViewReady) {
        // 调用 JavaScript 获取当前页的文本内容
        webView.evaluateJavascript("getCurrentPageText()", new ValueCallback<String>() {
            @Override
            public void onReceiveValue(String value) {
                if (value != null && !value.equals("null") && !value.isEmpty()) {
                    // JavaScript 返回的是 JSON 字符串，需要解析
                    String text = value;
                    // 移除引号（如果有的话）
                    if (text.startsWith("\"") && text.endsWith("\"")) {
                        text = text.substring(1, text.length() - 1);
                        // 处理转义字符
                        text = text.replace("\\n", "\n")
                                  .replace("\\t", "\t")
                                  .replace("\\\"", "\"")
                                  .replace("\\\\", "\\");
                    }
                    
                    // 截取前100字作为预览
                    if (text.length() > 100) {
                        text = text.substring(0, 100) + "...";
                    }
                    contentPreview[0] = text;
                }
                
                // 保存书签
                saveBookmark(chapterTitle, contentPreview[0]);
            }
        });
    } else {
        // 如果 WebView 未就绪，使用章节内容的前100字作为备选
        String fullContent = chapterContents.get(currentChapterIndex);
        if (fullContent != null && fullContent.length() > 0) {
            contentPreview[0] = fullContent.length() > 100 ? fullContent.substring(0, 100) + "..." : fullContent;
        }
        saveBookmark(chapterTitle, contentPreview[0]);
    }
}
```

**改进**：
1. **异步调用 JavaScript**：使用 `evaluateJavascript`
2. **解析返回值**：处理 JSON 字符串和转义字符
3. **截取前100字**：保持预览长度一致
4. **备选方案**：如果 WebView 未就绪，使用章节内容

### 修改点3：saveBookmark - 提取保存逻辑

**文件**：[ReadActivity.java#L1220-1240](file:///d:/android/app/app/src/main/java/com/example/myapplication/activity/ReadActivity.java#L1220-L1240)

```java
/**
 * 保存书签到 SharedPreferences
 */
private void saveBookmark(String chapterTitle, String contentPreview) {
    SharedPreferences sp = getSharedPreferences("local_bookmarks_" + currentBook.getId(), MODE_PRIVATE);
    int count = sp.getInt("bookmark_count", 0);
    
    SharedPreferences.Editor editor = sp.edit();
    int bookmarkIndex = count;
    editor.putInt("bookmark_count", count + 1);
    editor.putInt("bookmark_chapterIndex_" + bookmarkIndex, currentChapterIndex);
    editor.putString("bookmark_chapterTitle_" + bookmarkIndex, chapterTitle);
    editor.putInt("bookmark_page_" + bookmarkIndex, currentPageInChapter);
    editor.putString("bookmark_preview_" + bookmarkIndex, contentPreview);
    editor.putLong("bookmark_time_" + bookmarkIndex, System.currentTimeMillis());
    editor.apply();
    
    Toast.makeText(this, "书签已添加", Toast.LENGTH_SHORT).show();
}
```

**改进**：
- 将保存逻辑提取到独立方法
- 代码更清晰，职责分离

## 技术细节

### JavaScript 返回值解析

**JavaScript 返回的格式**：
```javascript
// 假设第8页有3行文本
return "第一行\n第二行\n第三行";

// evaluateJavascript 返回的是 JSON 字符串
"\"第一行\\n第二行\\n第三行\""
```

**Java 层解析**：
```java
String value = "\"第一行\\n第二行\\n第三行\"";

// 1. 移除外层引号
if (value.startsWith("\"") && value.endsWith("\"")) {
    value = value.substring(1, value.length() - 1);
}
// 结果："第一行\\n第二行\\n第三行"

// 2. 处理转义字符
value = value.replace("\\n", "\n")
             .replace("\\t", "\t")
             .replace("\\\"", "\"")
             .replace("\\\\", "\\");
// 结果："第一行\n第二行\n第三行"
```

### 备选方案

如果 WebView 未就绪（极少情况），使用章节内容作为备选：

```java
if (!isWebViewReady) {
```
