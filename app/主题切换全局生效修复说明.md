# 主题切换全局生效修复说明

## ❓ 问题描述

**用户反馈**：切换主题后，只有主题设置页面更换，其他页面没有变化。

## 🔍 问题分析

### 原因
Android的主题系统（`setTheme()`）只能在Activity创建时（`onCreate()`之前）应用。已创建的Activity无法动态更改主题样式。

### 之前的实现问题
```java
// ❌ 旧实现：只在当前Activity动态更新颜色
themeManager.switchTheme(theme, this);
applyThemeToActivity(activity, theme); // 只影响当前Activity
```

**结果**：
- ✅ ThemeSettingActivity立即更新
- ❌ 其他已打开的Activity（MainActivity、ReadActivity等）不更新
- ❌ 新打开的Activity会使用新主题

---

## ✅ 解决方案

### 策略：切换主题后重启应用

切换主题时，保存主题偏好，然后重启整个应用栈，确保所有Activity都使用新主题重新创建。

### 核心代码

#### 1. ThemeManager.java - 简化switchTheme方法

```java
/**
 * 切换主题（需要重启Activity以应用新主题）
 * @param theme 主题名称
 */
public void switchTheme(String theme) {
    if (theme.equals(currentTheme)) {
        return;
    }
    
    // 保存主题选择
    prefs.edit().putString(KEY_THEME, theme).apply();
    currentTheme = theme;
    
    // ❌ 移除了动态应用颜色的逻辑
    // applyThemeToActivity(activity, theme);
}
```

#### 2. ThemeSettingActivity.java - 添加重启逻辑

```java
private void selectTheme(String theme) {
    if (theme.equals(currentTheme)) {
        Toast.makeText(this, "当前已是该主题", Toast.LENGTH_SHORT).show();
        return;
    }

    // ✅ 切换主题（只保存偏好）
    themeManager.switchTheme(theme);
    currentTheme = theme;

    // 显示提示
    String themeName = getThemeDisplayName(theme);
    Toast.makeText(this, "已切换到" + themeName + "，应用将重启", Toast.LENGTH_LONG).show();

    // ✅ 重启应用以全局生效
    restartApp();
}

/**
 * 重启应用
 */
private void restartApp() {
    // 延迟500ms后重启，让用户看到Toast提示
    new android.os.Handler(android.os.Looper.getMainLooper()).postDelayed(() -> {
        // 启动MainActivity（清除所有Activity栈）
        Intent intent = new Intent(this, MainActivity.class);
        intent.setFlags(Intent.FLAG_ACTIVITY_NEW_TASK | Intent.FLAG_ACTIVITY_CLEAR_TASK);
        startActivity(intent);
        
        // 关闭当前Activity
        finish();
    }, 500);
}
```

### 技术流程
```
ThemeSettingActivity.selectTheme()
  ↓
ThemeManager.switchTheme()
  ↓ 保存主题到SharedPreferences
  ↓
ThemeSettingActivity.restartApp()
  ↓ 延迟500ms
  ↓
启动MainActivity (FLAG_ACTIVITY_CLEAR_TASK)
  ↓ 清除所有Activity栈
  ↓
MainActivity.onCreate()
  ↓ 从SharedPreferences读取主题
  ↓ setTheme(新主题)
  ↓
✅ 所有页面使用新主题
```

## 🔧 关键技术点

### 1. FLAG_ACTIVITY_CLEAR_TASK

```java
intent.setFlags(Intent.FLAG_ACTIVITY_NEW_TASK | Intent.FLAG_ACTIVITY_CLEAR_TASK);
```

**作用**：
- `FLAG_ACTIVITY_NEW_TASK` - 在新任务中启动Activity
- `FLAG_ACTIVITY_CLEAR_TASK` - 清除任务栈中的所有Activity

**效果**：完全清空应用栈，重新启动应用

### 2. Handler延迟执行

```java
new Handler(Looper.getMainLooper()).postDelayed(() -> {
    // 重启逻辑
}, 500);
```

**作用**：延迟500ms执行，让用户看到Toast提示

### 3. BaseActivity自动应用主题

```java
@Override
protected void onCreate(Bundle savedInstanceState) {
    // ✅ 在super.onCreate之前应用主题
    String theme = ThemeManager.getInstance(this).getCurrentTheme();
    setTheme(ThemeManager.getThemeStyleRes(theme));
    
    super.onCreate(savedInstanceState);
}
```

**效果**：所有继承BaseActivity的Activity都会自动应用当前主题
