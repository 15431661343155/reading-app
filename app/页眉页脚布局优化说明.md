# 页眉页脚布局优化 - 完成说明

## 需求描述

优化阅读器页眉页脚的布局和显示内容：

1. **页眉**：章节标题应位于最左侧（左对齐）
2. **页脚**：页码应位于最右侧（右对齐）
3. **本地书籍**：在页码右侧显示已读百分比

**关键点**：

- 绘制后重置对齐方式为left，避免影响其他绘制

## 阅读进度计算逻辑

```java
int bookProgress = (chapterList.size() > 0) ?
        (int)((currentChapterIndex + 1) * 100f / chapterList.size()) : 0;
```

**计算公式**：
```
bookProgress = (当前章节索引 + 1) × 100 / 总章节数
```

**示例**：
- 总共10章，当前在第3章（索引2）
- bookProgress = (2 + 1) × 100 / 10 = 30%

**注意**：这个计算包含了所有章节（包括特殊章节如"作者的话"等），所以显示的百分比是相对于总章节数的进度。

## 布局细节

### 页眉布局
- **位置**：顶部，距离上边距padding（16px）
- **对齐**：左对齐
- **起始X坐标**：padding（16px）
- **Y坐标**：padding + headerFooterFontSize
- **预留空间**：页眉高度 + 10px间距

### 页脚布局
- **位置**：底部，距离下边距15px
- **对齐**：右对齐
- **起始X坐标**：window.innerWidth - padding
- **Y坐标**：window.innerHeight - 15
- **内容格式**：
  - 网络书：`页码/总页数`（如"3/10"）
  - 本地书：`页码/总页数 百分比%`（如"3/10 30%"）

## 注意事项

1. **Canvas文本对齐**：每次绘制后需要重置textAlign，避免影响后续绘制
2. **坐标计算**：使用padding确保不会贴边，保持视觉美观
3. **参数传递**：确保Java层正确传递isLocalBook和bookProgress参数
4. **类型检查**：JavaScript中使用typeof检查参数是否存在，避免未定义错误
5. **进度计算**：当前使用章节索引计算进度，如果需要更精确的进度（考虑每章页数），可以改进算法
